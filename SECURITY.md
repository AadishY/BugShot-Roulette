# Security Policy

## Supported Versions

We provide security updates for the latest code on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

The safety and security of players and contributors is paramount. If you discover a security vulnerability or exploit (client-side execution vulnerability, server-side socket injection, etc.), please follow these responsible disclosure steps:

1. **Do not disclose the vulnerability publicly** in issues, pull requests, or community chat.
2. Reach out directly to the maintainer via GitHub:
   - Profile: [https://github.com/AadishY](https://github.com/AadishY)
   - Or open a private security advisory through GitHub Security Advisories if enabled on the repository.
3. Provide as much detail as possible:
   - A clear description of the vulnerability.
   - Proof of concept (PoC) or step-by-step reproduction instructions.
   - Impact assessment (e.g., unauthorized server command execution, score manipulation).
   - Any potential fixes or suggestions you may have.

## Response Timeline

- **Initial Acknowledgement**: Within 48 hours of report submission.
- **Assessment & Fix**: We will evaluate the report, verify the vulnerability, and prepare a patch as quickly as possible.
- **Public Disclosure**: Once a patch has been merged and deployed, coordinated public disclosure will take place with credit given to the reporter (if desired).

Thank you for helping keep Bugshot Roulette and its players secure!
